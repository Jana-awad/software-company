# dev.io — Software Company Website

A responsive website concept for **dev.io**, a software company offering custom
application development, software quality assurance, and maintenance and API
integration services.

## Features

- Responsive navigation with a collapsible menu on smaller screens
- Hero section introducing the company
- Services section with three service cards
- Footer navigation linking to services and page sections
- Locally included Bootstrap assets and custom CSS

## Built with

- HTML
- CSS
- Bootstrap

## Run locally

No build step or package installation is required. Clone or download the
repository, then open `index.html` in a browser.

For a local development server, open the project folder in Visual Studio Code
and use an extension such as Live Server.

## Project structure

```text
.
├── index.html              # Page content and layout
├── style.css               # Custom styles and responsive layouts
├── bootstrap.min.css       # Bootstrap styles
├── bootstrap.bundle.min.js # Bootstrap interactive components
├── logo1.png
├── logo2.png
└── images/                 # Images used by the service cards
```

## Customization

- Edit the page content and navigation in `index.html`.
- Update colors, spacing, and responsive styles in `style.css`.
- Replace the logo and service-card images with your own assets as needed.

This is a static front-end project; it does not currently include a backend or
working contact form.
